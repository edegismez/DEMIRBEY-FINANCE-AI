Pazartesi – Logo GO 3 bağlantı kontrol listesi
DEMİRBEY FINANCE AI · şirketteki Windows bilgisayarda yapılacaklar
Amaç: Logo GO 3'ün kurulu olduğu SQL Server'a yalnızca okuma yetkisiyle bağlanmak ve uygulamanın kullanacağı tabloları doğrulamak. Bu işlemlerin hiçbiri Logo'daki kayıtları değiştirmez. Toplam süre yaklaşık 30–45 dakika.

1. Önce öğrenin ve not edin

BilgiNeredenNot
Logo GO 3 sürümüLogo GO 3 → Yardım → Hakkında
SQL Server adı (ör. .\LOGO, BILGISAYAR\SQLEXPRESS)Logo bayiniz veya bilgi işlem; ya da keşif aracı bu bilgisayardaki SQL servislerini listeler
Logo veritabanı adıKeşif aracı veritabanlarını listeler
Firma no (3 hane) ve dönem no (2 hane)Logo'ya girişte firma / dönem seçim ekranı; araç da listeler
SQL yönetici hesabı (sa veya bayinin verdiği)Logo bayisi / bilgi işlem – şifreyi kimseyle paylaşmayın, Claude dahil
Logo Objects lisansı var mı? (ileride Logo'ya yazmak için, şimdilik gerekmez)Logo bayisi

2. Adımlar

  1. Yedek: Logo veritabanının güncel yedeği alınmış olsun (bayi / bilgi işlem).
  2. Bu klasörü (Pazartesi-GO3-Kurulum) USB veya e-postayla Logo'nun kurulu olduğu bilgisayara kopyalayın.
  3. Salt okunur kullanıcı: SQL Server Management Studio'yu yönetici hesabıyla açın → 2-Salt-Okunur-Kullanici-Olustur.sql dosyasını açın → içindeki <LOGO_DB> yerine veritabanı adını, <GUCLU_PAROLA> yerine sizin belirleyeceğiniz güçlü bir şifreyi yazın → Execute. (SSMS yoksa bu adımı Logo bayinize yaptırın.)
  4. Keşif: 1-Calistir.bat dosyasına çift tıklayın. Sırasıyla SQL Server adı, giriş türü (H seçip demirbey_ro ve 3. adımdaki şifre), veritabanı, firma no ve dönem no sorulur.
  5. Ekranda "Kullanıcı yalnızca okuma yetkili ✓" yazısını görün. "DİKKAT: yazma yetkisi var" çıkarsa 3. adımı kontrol edin.
  6. Klasörde oluşan Logo-Kesif-TARİH.zip dosyasını bu sohbete gönderin. İçinde şifre, müşteri veya çek kaydı yoktur; yalnızca tablo adları, satır sayıları ve durum kodu dağılımları vardır. Göndermeden önce açıp bakabilirsiniz.
Windows "bu dosya tanınmıyor" uyarısı verirse: dosyaya sağ tıklayın → Özellikler → "Engellemeyi kaldır" → Tamam. 1-Calistir.bat yalnızca bu araç için PowerShell çalıştırır, bilgisayarın güvenlik ayarlarını değiştirmez.

3. Uygulama sunucusu nerede çalışacak? (karar verin)

  • Seçenek A – Logo'nun kurulu olduğu Windows bilgisayar: en basit başlangıç; bilgisayar mesai dışında da açık kalmalı.
  • Seçenek B – Şirket ağında ayrı bir Windows bilgisayar / sunucu: daha sağlıklı; SQL Server'a ağ erişimi (port 1433) açılır.
  • Mac ve iPad'den ofis dışında erişim için: sabit IP veya VPN (bilgi işlem / internet sağlayıcınız).

4. Siz zip'i gönderdikten sonra benim yapacaklarım

  1. Logo'daki çek durum kodlarını uygulamanın renk ve kategorilerine eşlemek (ödenecek, tahsilatta, portföy, iskonto / teminat).
  2. Firma, dönem ve tablo adlarına göre gerçek okuma sorgularını kesinleştirmek.
  3. Sunucuyu sizin bilgisayarınızda kurmak için adım adım kurulum dosyası hazırlamak.
  4. İlk canlı ekranları açmak: Çek Takibi, cariler, stok; ardından nakit akışı ve raporlar.

Not: Bu araçların hiçbiri Logo'ya kayıt yazmaz. Kullanıcı yalnızca okuma yetkilidir ve araç da yalnızca okuma sorgularına izin verir.
